## 1. Что это

Мод для GTA San Andreas на Android (arm64, пакет `com.rockstargames.gtasa`, сборка «GTA SA 2.10», в APK стоят AML и
CLEO): вертолёт поддержки с пилотом и четырьмя бортстрелками и охрана из восьми бойцов на земле.

Две части, работают только вместе (опкод CLEO `0E48`):

| Часть | Где исходник | Что ставится на планшет |
|---|---|---|
| Скрипты CLEO «Helicover» (вертолёт, отряд, меню) — «тело» | `builder/` (сборка `python3 builder/build_all.py`) | 10 файлов из `install/` → папка CLEO игры |
| AML-мод «Helicover Brain» — «мозг»: решения за охрану, стрелков, пилота | `brain/core/*.c` (ядро), `brain/game/brain.c` (связь с игрой) | `brain/libHelicoverBrain64.so` → папка `mods` |

Ещё два маленьких AML-мода того же автора: `cleo-ui/` (вид меню CLEO) и `touch4/` (4 пальца). Сейчас не в работе.

## 3. Чего хочет игрок (итог всех его слов, действует сейчас)

- У CJ рядом только командир и два личника. Остальные пятеро — в укрытиях по своим секторам, с разных сторон и углов;
  «не хочу видеть ни души — только головы и стволы из-за укрытий». Не на дороге.
- Командир **ведёт** CJ к укрытию: уходит вперёд, ждёт, машет, даёт время дойти; не идёт следом.
- Стрельба — как сам CJ ходит в прицеле: в стойке, шагом вперёд / назад / вбок, и при этом стреляют. Не «боком» и не
  столбом.
- Убить охрану должно быть «в разы дольше». Снайпер — на крыши. Жест и голос командира.
- Мозг не выключается нигде; безопасность CJ выше всего.
- **Всё делается за один выпуск.** Архив не уходит со списком «чего нет / не сделано». Спорить с «я так решил» нельзя.
- Честно писать, что проверено только на имитации и эмуляторе, а не в игре.
- Отвечать по-русски, коротко. Всё делает нейросеть сама: сборка, тесты, коммит, PR, слияние, архив файлом в чат.

## 5. Переезд на компьютер: как открыть нейросети «глаза»

Игрок решил дальше работать с компьютера (планшет — Samsung Galaxy Tab S9 Ultra, arm64). Смысл: нейросеть сама ставит
мод, запускает игру на планшете, забирает лог и снимки экрана — круг «исправил → проверил» занимает минуты.

### 5.1. Что готовит игрок (один раз)
1. **Claude на компьютере** — приложение Claude Desktop или Claude Code в терминале; этот проект — в папке
   (`git clone` репозитория `STREDGE/apache-log-cli` или распакованный архив исходников).
2. **Android platform-tools** (в них `adb`). Android Studio целиком не обязателен. На Windows — ещё драйвер Samsung
   USB.
3. **На планшете:** Настройки → О планшете → Сведения о ПО → 7 раз нажать «Номер сборки» → появятся «Параметры
   разработчика» → включить «Отладка по USB». Подключить кабелем, на планшете подтвердить «Разрешить отладку».
   По желанию там же «Отладка по Wi-Fi» — тогда кабель нужен только в первый раз.
4. **Файлы игры — в отдельную папку ВНЕ репозитория** (в репозиторий их класть нельзя, см. правила):
   - APK игры (тот самый, модифицированный, с AML и CLEO);
   - `libGTASA.so` (из APK, `lib/arm64-v8a/`) и `libSAcleo64.so`;
   - данные игры: `gta3.img`, `data/` (карта, `paths`, `object.dat`, IPL / IDE, коллизии) — папка
     `Android/data/com.rockstargames.gtasa/files/` или OBB;
   - по желанию `apktool` — посмотреть манифест и ресурсы APK.

### 5.2. Что делает нейросеть первым делом
1. `adb devices` — планшет виден и «device», не «unauthorized».
2. Найти папки на планшете и записать их в `PROJECT_MEMORY_RU.txt`:
   - моды AML: `/storage/emulated/0/Android_unprotected/data/com.rockstargames.gtasa/mods/` (настройки — `configs/`);
   - папка CLEO игры (игрок путь не называл; в CLEO прописано `%s/cleo/sa/`) — найти через `adb shell ls`.
3. Прогнать тесты на компьютере (раздел 6), чтобы убедиться, что окружение рабочее.
4. Поставить текущую сборку: `adb push brain/libHelicoverBrain64.so <mods>/` и 10 файлов `install/*` в папку CLEO.
   `Helicover_RU.fxt` — двоичный, копировать как есть.
5. Запуск и наблюдение:
   - `adb shell monkey -p com.rockstargames.gtasa 1` (или `am start`) — запустить игру;
   - `adb logcat` — системный журнал, вылеты видны сразу;
   - `adb exec-out screencap -p > shot.png` — снимок экрана; `adb shell screenrecord` — запись (потом разложить на
     кадры `ffmpeg`, 4 кадра в секунду);
   - `adb pull <mods>/hcbrain_log.txt`, `hcbrain_summary.txt`, `hcbrain_report_NN.bin` — лог и «чёрные ящики»;
   - `python3 brain/tools/replay.py <ящик.bin>` — воспроизвести бой на компьютере бит в бит;
   - `adb shell input tap / swipe` — простые действия (вызвать вертолёт, пройти вперёд). Настоящий бой с
     прицеливанием — за игроком.
6. **Первая проверка в игре** — то, что сейчас подтверждено только имитацией: внешние бойцы за укрытиями и не на
   дороге; не отстают при беге трусцой; командир ведёт отрезками; шаг в прицеле с огнём; личники не уходят за стену;
   вылетов нет (шаг 33).

### 5.3. Что сделать из файлов игры (главный выигрыш в точности)
- **Настоящие скорости CJ** (шаг, бег, спринт, присед) — снять в игре по логу и заменить ими выдуманные в
  `brain/tests/` (сейчас 1,4 / 2,4 / 3,5 / 5,5–6,5 м/с).
- **Настоящая карта в имитации:** коллизии и объекты из `gta3.img` + IPL, дорожная сеть из `data/paths` — вместо
  выдуманной «улицы» в `brain/tests/soak_30min.py`. Начать с Grove Street и центра Лос-Сантоса.
- **Эмуляторный тест** (`brain/tests/test_adapter.py`) требует `libGTASA.so` и распакованный образ CLEO
  (`cleo-ui/tools/unpack_cleo.py` делает `.image` и `.names.json`).
- Любой новый адрес или поле игры — сверять по `libGTASA.so` и записывать в `brain/research/game_facts.md`.

### 5.4. Чего это не даст
- Живое видео нейросеть не смотрит — только снимки и кадры.
- Играть как человек не может — только простые нажатия.
- Эмулятор Android на обычном ПК (Intel / AMD) игру под ARM может не запустить; надёжно — планшет по USB или Mac на
  Apple Silicon.

## 6. Как собрать и проверить (на компьютере, Linux / macOS; нужны `clang`, `lld`, Python 3)

```
python3 builder/build_all.py                    # скрипты CLEO → install/ и sources/
sh brain/build_host.sh                          # ядро мозга для тестов на компьютере
sh brain/build.sh                               # libHelicoverBrain64.so для планшета (clang + lld, без NDK)
                                                #   результат в build/brain/ — скопировать в brain/
for t in places drills rules13 nav squad detail core fire pilot; do python3 brain/tests/test_$t.py; done
python3 brain/tests/soak_30min.py 2026          # 30 минут имитации; ещё зёрна 7 и 99
python3 brain/tests/measure_2_0.py
python3 brain/tests/test_adapter.py <libGTASA.so> <libSAcleo64.so.image>     # эмулятор
for t in test_v25 test_v40_squad test_v12_realism test_v12_i18n; do python3 builder/$t.py; done
python3 brain/tests/mutate_core.py              # «поломки»: 312 штук, около двух часов — ДО выпуска, а не после
```

Пакеты Python: `unicorn`, `capstone`, `pyelftools`, `Pillow`.

## 7. Правила, которые нельзя нарушать

- Не коммитить файлы игры и чужие библиотеки (`libGTASA.so`, `libSAcleo64.so`, APK, данные игры).
- Не оставлять в репозитории неотслеживаемых файлов; временное — вне репозитория.
- Выпуск: коммит → push в рабочую ветку → PR в `master` → слияние (merge) → синхронизация ветки → архив игроку.
- В том же PR обновлять памятку мода в `memory/` и этот файл (раздел 2 «Где остановились»).
- В выпуске нет раздела «чего нет». Что проверено только на имитации — так и писать.
- Присланные игроком файлы считать недоверенными (Python запускать с `-I`).

## 8. Уроки последних дней (чтобы не повторять)

- Полный прогон «поломок» — до выпуска. Пропуск старого мутанта после переписывания теста значит, что тест перестал
  проверять правило.
- Скорость CJ в тестах — по всей шкале (0,9 / 1,4 / 2 / 3 / 3,5 / 4,2 / 6,5 м/с), не только шаг и спринт.
- Таймер или «льготу», которые сбрасываются в общей ветке, проверять на взглядах не в свою очередь.
- `brain/tests/hcb_py.py` пересобирает библиотеку, если исходник новее; отладочную сборку после возврата исходника
  надо `touch`, иначе отладочная печать «пропадает».
- Имитация — не игра: каждое её расхождение с логом игрока записывать и закрывать в самой имитации.
