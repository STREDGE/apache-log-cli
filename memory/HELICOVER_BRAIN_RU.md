## 1. Что это и статус
- Отдельный AML-мод `libHelicoverBrain64.so` (папка `brain/`): принимает решения за охрану, бортстрелков и пилота
  Helicover. CLEO-скрипты остаются «телом».
- **План одобрен пользователем 15.11.2026** (раздел 8 — одобренный текст целиком, менять только по его слову).
- Статус: **этап 1 выпущен 15.11.2026 — `HelicoverBrain_0.1_stage1.zip` (мод-наблюдатель, версия 0.1), ждём проверку
  пользователя на планшете**: не вылетает ли, скриншоты с метками, файлы `mods/hcbrain_report.bin` и
  `mods/hcbrain_log.txt`. Присланный отчёт проиграть: `python3 brain/tools/replay.py файл [--all]`.
- Ядро второго этапа (модуль огня `hcb_fire.c`) уже написано и проверено на компьютере; в игре его приказы пока не
  исполняются — наблюдатель только записывает их в отчёт (по отчёту видно, что модуль огня сделал бы в настоящем бою).

## 2. Правила пользователя по этому моду (обязательные)
- Локально, бесплатно, без интернета; в пределах возможностей планшета.
- **Мозг не отключается нигде** (ни в «Mods Settings», ни в меню, ни в файле настроек); «глупого» запасного режима
  нет: Helicover без мозга не работает и прямо пишет причину.
- Умные все: личная охрана, бортстрелки, пилот. **Медика пока нет** (в плане закомментирован).
- Всё глупое в CLEO-скриптах удалять в том же этапе, где его заменяет мозг.
- Продумывать мелочи самому и на много шагов вперёд; после одобрения работать без остановок и вопросов,
  останавливаться только там, где нужна проверка на планшете.
- Безопасность CJ превыше всего (раздел «Жёсткие запреты» плана).

## 3. Файлы, сборка, тесты

  «чёрный ящик»). Писать поля только простыми типами по одному в строке: из этого же файла `brain/tests/hcb_py.py`
  строит зеркало структур для Python (ctypes) и сверяет размеры с C.
- `brain/core/hcb_core.c` — память о контактах, оценка угроз (FRIEND / NEUTRAL / WATCH / THREAT / ATTACKER + причина),

  `brain/core/hcb_fire.c` — кто из наших по кому стреляет: правило огня игрока, жёсткие запреты, раздача целей,

  стал угрозой и почему, сверка с решениями на планшете.
- `brain/research/` — разборы `libGTASA.so` и CLEO (факты, адреса, доказательства): `game_facts.md`,
  `brain_offsets_draft.h`, `bridge_facts.md`.
- `brain/game/brain.c` — адаптер игры (этап 1: наблюдатель). Читает пулы и поля напрямую, цели NPC — из задач

- `brain/game/gta_words.h` — 66 контрольных инструкций игры; пишется `python3 brain/tools/gen_words.py путь/libGTASA.so`.
- `sh brain/build.sh` — сборка для телефона (`build/brain/libHelicoverBrain64.so`; копия в `brain/`).

## 4. Факты игры и CLEO, на которые опирается мозг
- Полные таблицы с доказательствами — в `brain/research/` (G = база libGTASA, I = база образа CLEO). Главное:
- **Мост.** Основной: свой опкод через встроенный интерфейс плагинов CLEO (таблица `I+0x27d9b8`, слот 17
  `RegisterOpcode`); обработчик получает настоящий `CRunningScript*`, локальные переменные скрипта лежат подряд по
  `script+0x6c`. Обязательно «рукопожатие»: незарегистрированный опкод CLEO не пропускает, а исполняет его параметры
  как код. Запасной: хранилище 0DDC / 0DDD — `std::vector<{u32 key, u32 value}>`, заголовок `I+0x7d1f8` (begin, end,
  cap); менять можно только значения существующих ключей, только в потоке игры; CLEO очищает его при новой игре и
  загрузке. 0DD1 чужих библиотек не видит; адреса ниже 4 ГБ скрипту недоступны.
- Слоты скриптов с нашими людьми: `STATE = 0x48456A00`; `PUB` = +20..+26 (0 CJ, 1 вертолёт, 2 пилот, 3–6 стрелки),
  `GROUND_PUB` = +71..+75 (отряд), `LEAVE` = +416..+423, `FIRE` = +7 (правило огня).
- **Кадр.** Подмена GOT-слота `G+0x845438` (`CTheScripts::Process`, ожидается `G+0x3f3ad8`): до скриптов, только без
  паузы; у функции 5 вызывающих — защита «раз в кадр» по `CTimer::m_FrameCounter` (`G+0xbdc590`) или времени
  (`G+0xbdc558`). Слоты в RELRO: mprotect, как в Touch x4. CLEO-скрипты стартуют через 3 с после (пере)запуска.
- **Рисование.** Подмена GOT-слота `G+0x845ec8` (`CHud::Draw`, ожидается `G+0x51f6f0`); сам `CHud::Draw` не трогать —
  его уже перехватил CLEO. Прямоугольник: `CSprite2d::Draw2DPolygon` `G+0x6ee4a4` (s0–s7 пиксели, x0 = RGBA*).
  Мир -> экран: `CSprite::CalcScreenCoors` `G+0x6e9df8` (nearClip = 1). Экран: `RsGlobal` `G+0xc9b320` (+8, +0xc).
- **Пулы.** `ms_pPedPool` `G+0xbc3bb8`, `ms_pVehiclePool` `G+0xbc3bc0`; CPool: +0 объекты, +8 байты флагов (бит 7 =
  свободно), +0x10 размер; шаг педов 0x9c8, машин 0xc68; дескриптор = (индекс << 8) | флаг.
- **CPed.** Позиция: `m_pMat` (+0x18) ? mat+0x30 : ent+8; вперёд = mat+0x10; скорость +0x68 (×50 = м/с); модель
  +0x32 (i16); интеллект +0x538; `m_pPlayerData` +0x540; создан кем +0x548 (2 = миссия); состояние +0x54c (54 / 55 =
  мёртв); флаги +0x584 (в машине: +0x585 бит 0; стреляет: +0x586 бит 0; присел: слово 0 бит 26); отношения +0x63c
  (u32[5]: 0 уважает, 1 любит, 3 не любит, 4 ненавидит; бит = тип педа); здоровье +0x6ac; броня +0x6b4; машина
  +0x708; тип +0x720; оружие: слот +0x8dc (i8), тип = *(i32*)(ped + 0x730 + слот·0x20); последний урон: оружие
  +0x93c, кто +0x940, когда +0x948. Цель NPC — не поле, а задачи: `GetTaskUseGun` `G+0x5bcb80` (цель +0x28),
  `FindTaskByType(1000)` `G+0x5bc444` (цель +0x20), `GetTaskFighting` `G+0x5bcb20` (цель +0x20).
- **CVehicle.** Водитель +0x5a0; пассажиры +0x5a8 [8]; число +0x5e8; макс +0x5ec; огонь +0x5f8; здоровье +0x634;
  тип +0x738 (0 машина, 3 вертолёт, 4 самолёт, 5 лодка, 9 мотоцикл); обломок = статус 5 (байт +0x5a, биты 3–7).
- **События.** Каждый выстрел: GOT-слот `G+0x843f10` (`CEventGunShot::CEventGunShot`: x1 стрелок, s0–s2 откуда,
  s3–s5 куда). Урон по педу: `ComputeDamageResponse` (слот `G+0x83eba8`) либо опрос полей «последний урон».
  Взрывы `gaExplosion` `G+0xd28c78` (16 × 0x88), снаряды `gaProjectileInfo` `G+0xd29508` (32 × 0x38).
- **Прочее.** Игрок: `FindPlayerPed(-1)` `G+0x4efae0`; звёзды: `FindPlayerWanted` `G+0x4f0454` +0x2c; группа игрока:
  `ms_groups` `G+0xc89c20` (0x4a0 на группу, члены с +0x18); миссия: `IsPlayerOnAMission` `G+0x3f4158`; ролик:
  `G+0xba8925`; пауза: `G+0xbdc594 / 595`; видимость: `GetIsLineOfSightClear` `G+0x5075a4` (9-й аргумент в стеке).
- Уже проверено, что в `libGTASA.so` пользователя есть: `CCover` (своя система укрытий), `CPed::Say`,
  `CEntryExitManager`, `CGangWars`, события выстрелов и урона, `CProjectileInfo`, `CExplosion`,
  `CWorld::ProcessLineOfSight`, отношения `CAcquaintance`, группы `CPedGroups`, `IsPlayerOnAMission`,
  `CCutsceneMgr`, `BurstTyre`, прожектор вертолёта, задачи «бросок на землю», рукопашные, «взгляд на цель».

## 5. Грабли
- Дескриптор педа и дескриптор машины могут совпасть числом (оба — индекс пула << 8 | флаг). Для ядра id машин несут
  бит 31 (`VID` в `brain.c`); иначе пед с номером вертолёта считался «нашим». Нашёл эмуляторный тест.
- Тест «повёрнут / за целью» с граничным числом ничего не доказывает (уже было в бете 6): в тестах геометрии брать
  значения с запасом и проверять обе стороны порога.
- Время реакции считается от момента, когда стрелок ВЗЯЛ цель, а не от ответа о видимости (иначе +100 мс).
- Мозг думает тиками по 100 мс: времена в тестах кратны 100 мс.
- В CLEO незарегистрированный опкод не пропускается — его параметры исполняются как код: скрипт не должен вызывать
  опкод мозга до «рукопожатия».
- `CHud::Draw` и `CRunningScript::Process` перехвачены CLEO (первые инструкции переписаны) — не сверять и не трогать
  их начало; работать через GOT-слоты.
- Правка файлов памяток через python-скрипт в Bash была отклонена защитой — править их инструментом Edit / Write.

## 8. Одобренный план (текст как одобрен)

### Контекст
Бета 6 подтверждена на планшете («всё хорошо»). Новая цель: охрана и пилот ведут себя как живые люди,
защищающие президента, — сами оценивают обстановку и действуют, без «тупизма». Требования пользователя:
- локально и бесплатно, в пределах возможностей планшета;
- умные все: личная охрана на земле, бортстрелки, пилот;
- **медика пока нет** (в плане закомментирован, вернём при желании);
- всё глупое в CLEO-скриптах убрать, а не оставлять рядом с новым;
- продумать мелочи самому и на много шагов вперёд; после одобрения — работать без остановок.

Почему не CLEO: скрипт видит игру только через команды, думает раз в 0,1 с, у него 32 переменные и нет памяти о
противниках. Почему не языковая модель и не Python: решения нужны за доли секунды каждый кадр; модель отвечает
секундами, Python добавляет 20–30 МБ и сам ума не даёт.

### Решение
Новый AML-мод **Helicover Brain** (`libHelicoverBrain64.so`, папка `brain/`) на C. Работает в потоке игры каждый
кадр и видит её напрямую. CLEO-скрипты остаются «телом» (меню, вызов вертолёта, верёвки, создание людей); решения
принимает мозг.

- **Ядро (`brain/core/`, чистый C без игры).** Модель мира, оценка угроз, роли, тактика, пилот, речь. Собирается и
  на обычном компьютере — я гоняю его на тысячах смоделированных боёв без телефона.
- **Адаптер игры (`brain/game/`).** Читает игру и отдаёт приказы людям и вертолёту. Каждый адрес и инструкция
  сверяются с вашей игрой (как в «4 пальцах»).
- **Мозг не отключается.** Выключателя нет нигде: ни в «Mods Settings», ни в меню Helicover, ни в файле настроек.
  Helicover без мозга не работает вообще — «глупого» запасного режима не существует.
- **Мост к CLEO.** Общий блок данных: скрипты сообщают, кто «свои» и что приказал игрок; мозг возвращает решения.
- **Три уровня мышления.** Рефлексы — каждый кадр. Тактика — 5 раз в секунду. Замысел — раз в секунду.
- **Выбор целей — расчётом, а не очками «на глаз».** Для каждого противника оценивается, сколько урона он может
  нанести CJ в ближайшие секунды; цели раздаются так, чтобы этот урон упал быстрее всего.
- **Нагрузка.** Не больше ~1 мс на кадр; тяжёлые проверки размазаны по кадрам. При просадке мозг реже
  пересчитывает дальние и второстепенные вещи, но рефлексы и жёсткие запреты работают всегда в полную силу.

### Жёсткие запреты (безопасность CJ — не нарушаются никаким решением)
- Ни один выстрел, линия которого проходит ближе 2 м от CJ; ни один — если за целью CJ или свои.
- Никаких взрывов рядом: по машине в радиусе опасного взрыва от CJ и своих — только по шинам или водителю, и не
  ниже порога прочности. Вдали от CJ (например, погоня в 60 м позади) машину можно останавливать огнём.
- Никакого взрывчатого оружия у охраны.
- Вертолёт не снижается над CJ (кроме подбора по верёвке), не садится ближе безопасной дистанции (винты),
  повреждённый — сначала уходит в сторону от CJ, потом садится или падает.
- Охрана не отбирает управление у игрока, не толкает CJ, не занимает место водителя, не перекрывает двери и камеру.
- Свои — по отношениям самой игры: Грув, завербованные бойцы CJ, союзники по миссии, пассажиры CJ, подруга.

### Каталог поведения
**Восприятие и память**
- Видит: оружие в руках, прицеливание в CJ, выстрел и точного автора, попадания, гранаты, ракеты, коктейли, огонь
  на земле, горящие и несущиеся на CJ машины, стрельбу из машин, вертолёты, стрелков на крышах.
- Слышит: выстрелы и взрывы вне видимости — поворачивается на звук и поднимает тревогу.
- Помнит каждого противника: где видели, сколько стрелял, чем вооружён, куда ушёл; ждёт его из-за укрытия.
- Различает намерение, возможность и случайность (прохожий с битой идёт мимо — не цель).
- Учитывает ночь, дождь и туман: дальность опознания падает, как у людей.
- Знает, где находится: чужая территория банды, война за район, военная зона — заранее поднимает готовность.
- Замечает «хвост»: машину с врагами, которая долго держится за машиной CJ.
- Уровни тревоги: спокойно → настороже → угроза → бой → эвакуация; отбой постепенный.

**Как живые, а не роботы**
- У каждого свой позывной, скорость реакции (0,15–0,35 с, быстрее при тревоге), меткость, манера огня.
- Не поворачиваются мгновенно на 180°, наводятся не сразу, стреляют очередями разной длины, иногда промахиваются
  (но никогда — в сторону CJ).
- Головы и взгляды работают: осматривают свой сектор, задерживаются на подозрительном, поглядывают на CJ.
- В покое — оружие опущено, смена поз, редкая перекличка; при тревоге — оружие к плечу.
- Под обстрелом не стоят в полный рост: уходят в укрытие, приседают, отвечают оттуда.
- Раненый отходит назад и докладывает; отряд перестраивается на троих и двоих.

**Личная охрана на земле (4 бойца)**
- Роли: старший смены, личник, головной (идёт впереди по ходу CJ и первым выглядывает за угол), фланги, тыл;
  в бою — группа огня и группа прикрытия. Роли передаются, если кто-то выбыл или отстал.
- Кольца: личник в 1–2 м, отряд в 4–8 м, вертолёт — внешнее кольцо и наблюдатель.
- Строй (ромб / коробка / клин) подстраивается под шаг, бег, узкий проход, стену, машину, толпу; места строя
  проверяются: не на проезжей части под машинами, не в воде, не на краю крыши.
- У каждого сектор наблюдения: смотрят наружу, а не в спину CJ.
- Соразмерная сила: безоружного драчуна сбивают с ног руками; нож или бита вплотную к CJ — оружие; огнестрел —
  огонь на поражение. Подозрительного сначала берут на прицел.
- При угрозе личник встаёт между стрелком и CJ; остальные разворачиваются на угрозу, один держит тыл.
- На стоянке (CJ долго на месте) — не кольцо, а посты на подходах.

**Бой**
- Задача охраны — увести CJ, а не выиграть перестрелку: мозг сам решает, держаться или эвакуировать (число и
  оружие врагов, здоровье CJ, звёзды). Против танка и армии — сразу «уходим».
- Укрытия из собственной системы укрытий игры; выбор по направлению огня; горящая или побитая машина — не укрытие.
- Перебежки парами «один стреляет — другой бежит», подавление, обход с фланга, удержание угла, отход перекатами.
- Дисциплина огня: что за целью, не перекрывать друг другу линию, перезарядка по очереди.
- Граната, ракета, огонь: предупредить, отпрыгнуть (бросок на землю), закрыть CJ со стороны взрыва.
- Снайпер: определить направление, уйти за твёрдое укрытие с нужной стороны, ответить с вертолёта.
- Машина на CJ: предупредить с направлением, уйти с траектории; по ней — шины и водитель.
- **Подсказки CJ.** Охрана не может вести игрока за руку, поэтому говорит и показывает меткой: «за стену слева»,
  «к вертолёту — туда».
- Эвакуация: сжать кольцо, вызвать вертолёт, вести к точке подбора, прикрыть посадку; площадку сначала занять.

**Рядом с CJ в обычной жизни**
- CJ бежит — сопровождение бегом; крадётся — отряд приседает и молчит, вертолёт отходит выше.
- Машина: посадка по местам без суеты, высадка — охрана первой и осматривается. Мест не хватило (мотоцикл,
  двухместная) — отряд поднимается на вертолёт и идёт по воздуху, высаживается, когда CJ остановится.
- Вода: вертолёт зависает с верёвкой для подбора. CJ в самолёте или с парашютом — сопровождение на дистанции.
- Здание: двое заходят с CJ через дверь, двое держат вход (если движок позволит; иначе все держат вход).
- Магазин, дом, сохранение, ролик — охрана «вольно», огня нет.
- CJ погиб или арестован — отбой; после больницы или участка вертолёт сам прилетает забрать (настройка).
- Отставший догоняет бегом; безнадёжно застрявшего подбирает вертолёт. Выбывших заменяют при следующей высадке.

**Миссии и полиция**
- В миссии по умолчанию только оборона: не трогать людей миссии первыми, чтобы не сломать задание.
- Полиция без звёзд — не враг. Со звёздами — настройка: «уводить CJ» (не убивать полицейских, эвакуация) или
  «отвечать тем, кто стреляет».

**Бортстрелки**
- Цели от мозга: по опасности, по сектору борта, по чистоте линии; двое на главную угрозу, остальные держат
  стороны. Один — наблюдатель: докладывает крыши, машины на подходе, «хвост».

**Пилот**
- Сам выбирает высоту и позицию под углы стрелков и обзор; в тумане и дожде летит ниже и медленнее.
- Прячется за зданиями, не подставляет борт, уходит от ракеты и от огня вертолёта полиции.
- Площадку и точку подбора оценивает: ровно, без препятствий, подальше от угрозы, поближе к CJ; под огнём —
  «горячий» подбор без посадки.
- Сопровождает машину CJ с упреждением; идёт вперёд по маршруту к метке и докладывает, что там.
- Обходит запретные зоны (военная база, авианосец): туда не летит без приказа и предупреждает.
- Ночью подсвечивает цель прожектором (если движок позволит).
- Докладывает намерения заранее. Второй вертолёт — позже, отдельным решением.

**Речь и голос**
- Доклад собирается из частей: кто, что видит, направление, дальность, число, чем вооружены, что делаем.
  Говорит старший, а не все сразу; без пустой болтовни.
- Бойцы произносят подходящие реплики голосом из самой игры (если движок позволит).
- Строка оповещений беты 6 остаётся каналом вывода.

**Память и самонастройка**
- Мозг запоминает места, где на CJ нападали, и манеру игры (CJ рвётся вперёд — строй смещается вперёд);
  хранит это в небольшом файле между запусками.

### Инструменты, без которых это не довести вслепую
- **Чёрный ящик.** Мозг пишет последние минуты (что видел, что решил и почему). Пункт меню «СОХРАНИТЬ ОТЧЁТ» —
  пользователь присылает файл, я проигрываю тот же бой у себя и вижу ошибку.
- **Метки на экране** (включаются): кто угроза, кто в какой роли, куда мозг советует идти.
- **Симулятор боёв с оценкой.** Учебные тревоги по настоящей доктрине охраны: нападение спереди, с тыла, с
  фланга, засада у машины, снайпер, граната, таран, толпа, потеря бойца. Оценки — время до прикрытия CJ, урон
  по CJ, выстрелы вблизи него. Параметры мозга подбираю по тысячам прогонов.

### Настройки (в «Mods Settings» и меню Helicover)
Только то, что задаёт предпочтения, а не «ум»: правила огня (оборона / вооружённые / куда стреляю я / не
стрелять); полиция (уводить / отвечать); в миссиях (оборона / как обычно); возврат после больницы; метки;
«сохранить отчёт»; «УХОДИМ» — эвакуация одной кнопкой. Выключателя мозга среди настроек нет и не будет.

### Этапы
Каждый этап — отдельная версия с архивом.

0. **Хвост беты 6.** Тест на язык строки счётчика убитых, догнать оборванную перепроверку (71 из 192), памятка.
1. **Разведка, наблюдатель, чёрный ящик.** Разбор игры и CLEO, мост. Мод ничего не меняет: лог (в том числе
   память и процессор планшета), метки, отчёт. Нужна проверка пользователя: не вылетает ли, и файл отчёта.
2. **Глаза, память, угрозы, запреты.** Свои и чужие из игры, правила для миссий и полиции. Стрелки и отряд берут
   цели у мозга; прежний выбор целей в скриптах удаляется.
3. **Личная охрана.** Роли, кольца, строй, секторы, «как живые», соразмерная сила. «Мозг» отряда в CLEO
   удаляется; медик выключается.
4. **Бой.** Укрытия, перебежки, подавление, гранаты, снайпер, машины, эвакуация, подсказки CJ.
5. **Рядом с CJ.** Транспорт, вода, здания, скрытность, стоянка, возврат после больницы, замена выбывших.
6. **Пилот.** Полётные решения переезжают из Core в мозг.
7. **Речь и голос.**
8. **Память и самонастройка.**
9. **Чистка и выпуск.** В скриптах остаётся только «тело»; версия без «бета».
10. **Опыт с локальной языковой моделью** — только свободные реплики, по умолчанию выключена; не обещаю.

Режим работы после одобрения: иду по этапам без вопросов. Ядро пишу и проверяю в симуляторе, не дожидаясь
телефона. Останавливаюсь только там, где нужна проверка на планшете; следующую версию для игры выпускаю
после подтверждения предыдущей.

Переход честно: часть, до которой этап ещё не дошёл (например, пилот до этапа 6), пока работает по-старому.
Всё, что уже переведено на мозг, назад не переключается — старая логика этой части удаляется в том же этапе.

### «Тупизм» в CLEO, который уходит
- Поиск целей «случайный человек из клетки» — угрозу можно не замечать несколько секунд.
- Признак «стреляет» опрашивается раз в 150–600 мс, хотя живёт один кадр; стрелок угадывается по следам пуль.
- Раздача целей раз в 1,5 с; задачи огня переиздаются по таймеру, а не по событию.
- Отряд: решения по таймерам (перезарядка каждые 10 с боя, «ждать 25 с у верёвок»), строй без секторов.
- Полёт: фиксированные орбиты и высоты, посадка по пяти пробам земли.
- Список «своих» по моделям, продублированный в каждом скрипте, — будет одно место и отношения самой игры.

Запасного «глупого» режима нет. Единственный случай, когда мозг не может работать, — файл игры не тот, под
который он собран (сверка инструкций не сошлась). Тогда Helicover не вызывает вертолёт и прямо пишет причину;
работать «как-нибудь» без мозга он не станет.

### Ограничения, о которых сказано пользователю заранее
- Бойцы остаются персонажами GTA: анимации и поиск пути — игровые; «как живые» — в пределах движка.
- Пункты с пометкой «если движок позволит» (вход в здания, голос, прожектор) могут не получиться — сказать прямо.
- Родной код может вылетать — поэтому каждая инструкция сверяется с игрой до включения. Если версия с мозгом
  вылетит на планшете, откат один: поставить предыдущий архив и прислать отчёт. Выключателя «на всякий случай»
  не будет.
- Это много версий; первые видимые изменения поведения — с этапа 2.
