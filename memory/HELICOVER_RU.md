## 2. Файлы, сборка, тесты, выпуск
- `builder/asm_v25.py` — ассемблер CLEO (таблица опкодов sa_mobile + добавленные вручную).
  `Script.add(op, args)`; `check(op, [args], label)` — прыжок, когда условие ЛОЖНО; `op | 0x8000` — отрицание;
  `eq(var, val, label)` — прыжок, если НЕ равно; `call / ret / go`, `blob`, `set / get` (общие слоты 0DDC / 0DDD).
  Полярность: 0x0019 `var > n`, 0x0021 float `var > n`, 0x0023 `n > var`, 0x001d int `a > b`, 0x0025 float `a > b`,
  0x003b int равно. ПРИ КАЖДОЙ ПРАВКЕ УСЛОВИЙ перепроверять полярность (уже были перевёрнутые условия).
- `builder/build_v25.py` — Core (вертолёт, состояния, шлюз команд), Panel (меню), Launcher (`Helicover.csi`), Fire
  (бортстрелки). `builder/build_v25_ground.py` — верёвки, отряд на земле (Ground). `builder/build_v25_squad.py` —
  тактика отряда (Squad). `builder/msg_v42.py` — сообщения (`say`, приоритеты, язык). `builder/i18n_v12.py` — русские
  тексты и раскладка шрифта. `builder/threat_v41.py` (доска угроз, очки, чтение следов пуль) УДАЛЁН в 1.3.
- `builder/brain_mock.py` — имитация мода мозга для тестов скриптов: строит снимок мира из `World`, решения принимает
  НАСТОЯЩЕЕ ядро (`brain/tests/hcb_py.py`, сборка для компьютера), отвечает на `0E48` (стрелок / боец / обстановка),
  рукопожатие. Читает из мира: `shooting_chars` + `shot_at` (кто и куда стреляет), `shooting` + `cj_aim` / `targeting`
  (огонь CJ), `damage`, `npc_target`, `wanted`, `on_mission`, `mission_peds`. Видит ВСЕХ людей мира, а не только
  `w.civilians`.
- `builder/build_all.py` — ВСЕГДА собирать через него: строит всё, пишет FXT, проверяет ключи, копирует в `install/` и
  `sources/`.
- Тесты (имитация игры на Python, `World` / `VM` в `test_v25.py`; остальные наборы берут её через `exec`):
  `test_v25.py` (119), `test_v40_squad.py` (102), `test_v12_realism.py` (75), `test_v12_i18n.py` (47) = 343 (1.3).

## 3. Как устроено

### Скрипты и общие переменные
- Общие слоты 0DDC / 0DDD от `STATE = 0x48456A00`: `CMD` +1, `HEART` +2 (метка времени Core каждый проход), `OPEN` +3,
  `PANELHEART` +4 (метка времени Panel). Полный список — в начале `build_v25.py`. Занято до +464
  (+410 и 429–432 свободны): 406 ROPE_BUSY, 407 SWAP_MSG, 408 TEAM_CREW, 409 LANG, 411 DISMISS_T, 412–414 PB_AIM,
  415 ROPE_WAIT, 416–423 LEAVE, 424 LEAVE_N, 425 AFTER_ROPE, 426 DISMISS_NEXT, 427 LEAVE_ROT, 428 NAP_UNTIL,
  433 BURN_NEXT, 434 BURN_SAID, 435 POSE (1 с колена), 436 POSE_DONE, 437 MSG_ID, 438 BANNER_ARMED, 439 MSG_HOLD.
  1.3 (мозг): 440 BRAIN_HELLO (скрипт создаёт 0, мозг пишет `0x42520021`), 441 POLICE (1 = не стрелять),
  442 MISSIONS (1 = как обычно), 443–446 G_AIM (на кого стрелок навёл оружие), 447–450 G_AIM_T, 451 BR_ALERT,
  452 BR_TOP, 453 BR_KILLS, 454 BR_THREATS, 455 BR_ATTACKERS, 456–459 SQ_BR_ST (слово мозга бойцу: 0 ничего,
  1 прикрывай, 2 огонь, 3 «твой, но не стрелять»), 460–463 SQ_BR_TG (его человек), 464 SQ_TICK. Из старых слотов
  живы `HELI_SHOT_T` +254, `CJ_AIM_X/Y` +369 / +370, `CJ_AIM_T` +375 — теперь их пишут по словам мозга.
- Состояния Core: 0 нет вертолёта, 1 подготовка (в игре кадр-два), 2 следует, 3 зависание, 4 / 13 улетает, 5 / 6 сбой,
  7 / 11 / 15 посадка (15 аварийная), 8 / 9 / 12 на земле, 10 / 20 полёт на Гроув-стрит, 14 сбор экипажа,
  16 / 17 замена модели / экипажа, 18 «посадка невозможна», 19 подлёт для верёвки, 21 / 25 / 22 полёт к метке,
  23 ожидание выхода, 24 патруль.
- Приказы (`CMD`): 1 вызвать, 2 следовать, 3 ждать, 4 отпустить, 7 Гроув, 10 верёвка, 11 метка, 14 патруль,
  15 выход, 16 высадить отряд, 17 забрать отряд.
- Отряд: `ESCORT_ON` 0 нет, 1 на земле, 2 спускается, 3 возвращается, 4 потерян, 5 отпущен; `ESCORT_PENDING` 1 / 2 —
  подлёт для высадки / возврата; `ESCORT_CMD` 1 высадить, 2 забрать, 3 эвакуация; `ROPE_COMMAND`, `DROP_COMMAND`.

### Память игры (сборка пользователя, `GAME_OK` = STATE+330 проверяет подпись)
- Метка карты: `gMobileMenu+0x68` (0x8BE780+0x68), `RADAR_TRACE_OFS` 0xC21728. Опкод 0AB6 на CLEO Android вылетает.

  у 06BC и полицейского вертолёта. След читается как ЛИНИЯ.
- 02E0 IS_CHAR_SHOOTING живёт ровно один кадр (ставит `CWeapon::Fire`, сбрасывает `CPed::ProcessControl`) — опрос
  каждый кадр.
- 009A CREATE_CHAR прибавляет 1.0 к z; 046C — водитель машины (игрок тоже, нет -> −1); 05DE TASK_WANDER_STANDARD

### Оповещения (бета 6)
- В мобильной игре окно подсказок (03E5) — очередь `CWidgetHelpText`: 10 мест, 5,0 с на сообщение + 0,65 с затуханий,
  новое никогда не заменяет текущее; 03E6 сокращает текущее до 0,125 с, но всё равно 0,8–1,1 с. Для живых оповещений
  не годится.
- `say()` (msg_v42.py) пишет слоты `MSG_ID` (номер в `msg_v42.KEYS` = sorted(RU_MESSAGES), 127 ключей), `MSG_UNTIL`,
  `MSG_PRIO`, `MSG_HOLD`. Рисует Fire: `BANNER` в начале `WAIT` каждый кадр — `03F0 1`, `033F 0.5 1.4`, `0340` белый,
  `0342 1`, `0344 352`, `081C 1` чёрный, `033E 320 3 KEY`. Первый кадр только включает 03F0 (`BANNER_ARMED`).
- Факты игры: 03F0 ≠ 0 — глобальный флаг, строки текста стираются в начале каждого `CTheScripts::Process` (рисовать
  каждый кадр); при 96 накопленных строках 033E не читает параметры (рассинхрон скрипта); пространство 640×448, x — в
  центральной области 4:3; размер шрифта = высота·H/448/2, ширина в 033F игнорируется; шаг строки 18·масштаб; перенос
  по 0344·W/640; шрифт по умолчанию 1; теги цвета работают; не рисуется при `m_UserPause`, фото и «большом» сообщении.
  CLEO запускает свои скрипты через `StartNewScript` — их исполняет цикл игры после сброса строк.
- Параметры (из обработчиков): 033E x y key; 033F 2; 0340 4; 0342 1; 0343 1; 0344 1; 0345 1; 0348 1; 0349 1;
  060D 5; 081C 5; 03F0 1; 038E 8 (x, y — центр); 03E6 0; 08FE 0.
- Кто занимает строку: приоритет 4 — всегда; равный или выше — сразу; на уровень ниже — после `MIN_SHOW_MS` 1,2 с;
  ниже — после конца. `ORDER_ACK` (подтверждения приказов) — сразу при любом содержимом, держатся как тревога.
- В тестах сообщение = запись в `MSG_ID` (имитация добавляет ключ в `w.messages`); что нарисовано — `calls(w, 0x33e)`.

### Правила мода (каждое закрыто тестом)
- Никаких телепортов людей: вертолёт создаётся на кольце 160 м вне поля зрения и улетает из виду; отставший бежит,
  через 60 с за 70 м отпускается; у верёвок ждут 25 с.
- Живого бойца никогда не отдают игре (01C2): в поле зрения — `LEAVE_ADD` (оружие убрано, уходит 05DE / выходит из
  машины 0633, 8 слотов, девятый вытесняет самого старого), вне поля зрения — удаление; Fire считает уходящих своими.
- Шлюз команд в Core (метка `GATE`): повтор включённого режима и полёта к той же метке — пропуск; `SQUAD_MOVING` —
  16 / 17 молча, 10 с «подождите»; пока верёвка выпущена для CJ (`ROPE_WAIT`): 10 = отмена, 17 = отряд вверх по этим
  верёвкам, 16 = группа прикрытия остаётся отрядом, 2 / 4 / 14 при группе прикрытия = отмена + `AFTER_ROPE`; при
  `ROPE_BUSY` — отказ `HCRBSY`; повтор выхода отбрасывается, пока выход уже идёт.
- Ground читает запросы шлюза в `ACT_NOT_BUSY` только после приземления группы; `ROPE_BUSY` = 1 с момента принятия
  заказа, снимается в `CLEANUP` до любых приказов.
- **Огонь (1.3): решает мозг, скрипт исполняет.** Fire каждый кадр: обстановка `0E48 8@ 9 3` (тревога, угрозы,
  нападающие, убитые, главный, огонь CJ ×3, мс с выстрела чужого по вертолёту) -> слоты BR_*, `HELI_SHOT_T`,
  `FIRE_TARGET` для пилота (только пока правило огня не «не стрелять»), счётчик убитых (первое число мозга после
  старта скрипта — не новое убийство), «контакт» при нападающих > 0, «чисто» через 3 с без угроз. Затем на каждого
  стрелка `0E48 8@ 9 1`: состояние 2 -> пуля 06BC ровно по линии мозга (урон 30); 1 / 2 -> оружие на человека задачей
  0667 (она НЕ стреляет), заново каждые 0,7 с; 0 -> `rest()`. Задач огня оружием игры у стрелков нет вообще
  (074D / 0713 / 0668 стреляют непроверяемыми пулями). Стрелок, не прикреплённый к вертолёту (0A32 ложно), пуль не
  получает. Нет вертолёта (состояния 0 / 1 / 5 / 6 / 16) -> `NO_HELI`: ENGAGED, FIRE_ACTIVE, FIRE_TARGET сброшены.
  Нет рукопожатия -> никто не стреляет, Core не вызывает вертолёт (`HCNOBR`).
- Squad: `BRAIN_FRAME` каждый кадр спрашивает `0E48 26@ 3 2` на каждого бойца (SQ_BR_ST / SQ_BR_TG) и, если боец на
  задаче огня (TASK 3 / 8 / 10 / 12), а мозг сказал 3, — в том же кадре ставит ему 0667 (TASK 18). Полный проход
  тактики — раз в 100 мс (`801D`). Любая задача огня — только через `may_fire(k)` (состояние 2). Выбора и оценки
  целей, подавляющего огня «по месту» в скрипте нет. Радио: вид угрозы (снайпер / машина / крыша / обычный) по
  главному человеку мозга.
- Пороги (40 м / ±40°, прочность машины 700, 2 м до CJ, 1 м до своих) — теперь настройки ядра (`hcb_cfg`), в скриптах
  их нет; тесты берут их из ядра (`brain_mock.h.Brain().cfg` — объект Brain держать живым).
- Меню огня (страница 1): ЗАЩИЩАТЬ МЕНЯ (3) / ТОЛЬКО ВООРУЖЁННЫЕ (4) / ТАМ, ГДЕ СТРЕЛЯЮ Я (2) / НЕ СТРЕЛЯТЬ (0);
  ПОЛИЦИЯ: ОТВЕЧАТЬ / НЕ СТРЕЛЯТЬ; МИССИИ: ОБОРОНА / КАК ОБЫЧНО; НАЗАД. «Огонь по всем» (1) убран.
- `BURN_WATCH`: горящая машина (< 250, не обломок) в 12 м от CJ -> `HCBURN`, раз в 4 с.
- Свои не трусят: `brave()` = `060B ped 65542` (встроенное пустое поведение m_empty, слот 6) под проверкой 09F2 — у
  пилота, стрелков, нового экипажа и в `GSETUP` отряда. 05C5 TASK_DUCK нигде не использовать (испуганная поза);
  присесть с оружием — 04EB 1 / 0.
- Стрелки на полозьях с колена: после 0464 — 04EB 1 при `POSE` = 1; настройка «СТРЕЛКИ: С КОЛЕНА / СТОЯ»; `CHANGE_POSE`
  в тике Core (перевесить один раз + `ARM_CREW`); в Fire каждое 0687 через `rest()` (снова 04EB 1).
- Язык: русский только при `GAME_OK` и флаге 0xCE1771, иначе английский; `RESOLVE_LANG` каждый проход Core.
  Раскладка шрифта «Русского»: А–Я 0x80–0x9F, а–я 0xA0–0xBF, Ё нет. FXT: ключи H… (англ.), U… (рус.).
- Меню (Panel): страницы 0 главная, 1 огонь, 2 настройки (6 строк + НАЗАД; ключ pose·100 + tac·10 + hud), 3 экипаж, 4 модель, 5 оружие,
  6 подтверждение «отпустить». Ключ главной: state·1000 + sit·100 + x (sit 0 нет вертолёта, 1 занят, 2 на земле,
  3 на борту). Строки хода: `TEAM_PHASE`, `ROPE_PHASE`. На борту строки «КНОПКА ВЫХОДА» — переключатели `EXIT_MODE`.
- Защита касаний (Panel, `HAS_PICK`): 0,35 с после принятого касания или смены страницы; на главной та же строка —
  раз в 1 с (считаются и отброшенные касания); касание по устаревшей странице только перерисовывает.
  Локальные Panel: заняты 0–29 (29 — срок запасной проверки Core), свободны 30–31. Пускач: 1–3.
- Открытие меню без пауз (бета 5). «Пульс» = метка времени игры 01BD. Пускач (`Helicover.csi`): `PANELHEART` не
  старше `PANEL_FRESH_MS` 1000 мс -> `OPEN` = 1 сразу; Panel (`ACQUIRE`): `HEART` не старше `CORE_FRESH_MS` 1500 мс ->
  сразу страница. Метка 0, устаревшая или «из будущего» (загрузка сохранения) -> запасной путь, прежняя проверка:
  ждать СМЕНЫ метки не дольше `PANEL_PROOF_MS` 650 мс (иначе «нет файлов» HCOFF / UCOFF) и `CORE_PROOF_MS` 250 мс
  (иначе страница OFFLINE). Устаревшая метка сама по себе никогда не значит «скрипта нет».
- Опрос Panel: `WATCH` и `MENU_POLL` каждый кадр (wait 0), `OFFLINE_POLL` 50 мс. После нажатия строки паузы нет:
  `CMD` записан -> `CHECK_MENU_STATUS`.
- Тик Core: подпрограмма `NAP` вместо wait 100 (в `IDLE` и `TICK_NORMAL_WAIT`): `NAP_UNTIL` = сейчас + 100, цикл
  wait 0 до этой метки, выход сразу при `CMD` != 0. Без приказов — те же проходы раз в 100 мс; приказ забирается
  за 1–2 кадра. Состояния 10 / 19 / 21 / 22 при `FROZEN` — по-прежнему каждый кадр; `DEPART_TICK` — wait 100.
  Регистры `NAP`: 17 и 19 (временные). Любой приказ Core обнуляет `CMD` за проход (тест перебирает 1..39 в 6 ситуациях) —
  если появится состояние, которое оставляет `CMD` висеть, `NAP` выродится в покадровый цикл.
- «Отпустить вертолёт» (`DISMISS_TICK`): ждёт верёвки и отряд, просит отзыв раз в 6 с, через 45 с улетает без отряда.
- «Там, где стреляю я» (1.3): цели — люди, по которым стреляет CJ, и экипаж машины, по которой он стреляет (метит
  мозг по выстрелам CJ). Следы пуль скрипты больше не читают. Нагрузку мерить при 30 к/с (`frame_ms = 33`): в бою
  с 8 нападающими Fire — пик 365 / в среднем 242 инструкции на кадр (было до 3600), Squad — 1034 / 209.
- Сообщения: `say(s, key)`; приоритеты 4 действие / 3 тревога / 2 тактика / 1 болтовня; уровень HUD 2 / 1 / 0;
  длина текста ≤ 66 знаков.

## 4. Грабли
- Обе раскладки русского в бетах 1–2 (CP1251 и «клавиатурная» по `russian_table`) дали мусор: `russian_table` к шрифту
  не относится. Не выводить раскладку из бинарника без экрана. SanLTD — другой шрифт; пользователь его не хочет.
- v41 / 1.1: считал след пули точным отрезком — «стрелок по следу» почти не находился. Сказано пользователю.
- Перевёрнутые условия (бонус тяжёлого оружия, чтение следов во время стрельбы) — проверять полярность опкодов.
- Проба нагрузки только в одном режиме пропустила пик 5063 инструкций в «там, где стреляю я».
- Тест, который ищет «?» как признак нечитаемого знака, сталкивается с настоящим «?» в тексте — использовать U+FFFD.
- В имитации: состояние 1 длится один кадр; отряд «приземляется» мгновенно — держать на верёвке через
  `w.ped_heights`; `command()` шагает только Core — остальные скрипты шагать отдельно; между нажатиями одной строки
  в тестах нужна пауза ≥ 1 с.
- Мутант может «пройти», если тест смотрит не туда (стрельба по координатам 06BC без дескриптора цели) — проверять
  `FIRE_TARGET` и сам факт выстрелов.
- Фиксированные паузы «для проверки, что скрипт жив» (400 + 250 + 250 мс) давали секунду задержки открытия меню.
- `NAP` сначала сравнивал «сейчас > срок» — при 10 к/с тик Core стал 200 мс вместо 100 (поймали старые тесты скорости
  полёта). Нужно «сейчас >= срок»: `check(0x801d, [срок, сейчас], 'NAP_LOOP')`.
- Ускорение приёма приказа сдвигает на кадр «стартовые» кадры в тестах, которые телепортируют вертолёт посреди паузы
  Core (тест скорости подлёта к верёвке пропускает первые 4 кадра).
- 0DF4 (опрос меню) имеет аргумент 250 — возможно, CLEO сообщает о касании до 0,25 с подряд. Страница теперь меняется
  сразу, поэтому защита касаний (0,35 с) обязательна: тест «залипшего» касания это проверяет. Не уменьшать 0,35 с
  ниже 0,25 с.
- Поведение педов: `CREATE_CHAR` даёт m_norm.ped («присесть-закрыться» / бегство на удар, выстрел, прицел). 060A типы:
  0 m_empty, 1 m_norm, 2 m_tough, 3 m_weak, 4 m_steal; скрипту доступны только слоты 10–14, таблица сохраняется в сейве
  (утечка слота на каждую загрузку) — поэтому берём встроенный 65542, а не 060A. Поведение «дать сдачи» может
  обратить педа против CJ — не использовать.
- Старые тесты считали целью любого бандита: в тестах «защищать CJ» цель надо делать угрозой (`threaten(w, npc)` —
  оружие в руках и поворот к CJ) или нападавшим (`w.damage`).
- Мутант «повернут к CJ» прошёл, потому что тест поворачивал цель ровно на 180° (граничное значение обоих сравнений) —
  в тестах углов брать не кратные 180. Мутант «оружие вниз сразу» прошёл из-за совпадения с раздачей задач — в тесте
  сначала дождаться свежей раздачи (`FIRE_TASK_NEXT`).
- 1.3: скрипт НИКОГДА не вызывает `0E48` до рукопожатия (CLEO исполнит параметры незнакомого опкода как код): каждый
  вызов стоит за проверкой `BRAIN_HELLO == BRAIN_MAGIC`; имитация падает, если опкод вызван без мозга.
- 1.3: полный проход Squad сначала сравнивал «сейчас > срок» и шёл раз в 200 мс при 10 к/с — нужно `801D`
  (та же ошибка, что была в `NAP`).
- 1.3: после удаления кода из сборщика чистить и список мутантов (`tools/mutate.py`): мутант, чей файл удалён, ронял
  инструмент; теперь он печатает GONE, а список прорежен (было 265, стало 204).
- Тестовые скрипты-пробы собирать вне `build/` (иначе `build_all` копирует их в `install/`).
- Запись `MSG_ID` при инициализации имитация принимает за сообщение — не инициализировать этот слот.
- Не знаю, идут ли скрипты и время игры, пока открыт список CLEO: поэтому у проверки «пульса» есть запасной путь, а
  не сразу «нет файлов».

## 5. Пожелания пользователя
- Меню только через CLEO; язык следует за языком игры (русский стандарт -> русский, иначе английский), выбора языка
  в меню не нужно.
- Высадка только кнопкой выхода; строки на борту — переключатели.
- Декор (модель, форма, оружие) меняется сразу, без «реализма».
- Повторные нажатия ничего не должны ломать; «идеальная логика всего мода», удобно.
- Меню должно открываться и реагировать сразу, плавно.
- Оповещения — сразу, по факту, не накладываясь. Отряд — «спецназ», не трусит. Бортстрелки — умные, быстрые, не
  стоят столбом. Безопасность CJ превыше всего: охрана не должна мочь его убить (взрыв машины и т. п.).
- Просил «продумать на 1000 шагов вперёд» — предлагать и делать смежные улучшения безопасности самому.
- Не коммитить файлы игры. Архив присылать файлом в чат.
