## 1. Что это и статус
- CLEO-мод для GTA San Andreas Android: вертолёт поддержки (пилот + 4 бортстрелка), отряд из 4 бойцов на земле,
  подъём / спуск по верёвке, полёт к метке карты и на Гроув-стрит, меню в CLEO.
- **Версия 1.2 бета 5** (PR #38; бета 4 — PR #33). Опубликованная версия для сайта — 1.0; 1.2 выйдет без «бета» после отзыва.
- Подтверждено пользователем на планшете: русский текст на стандартном «Русском» игры читается идеально; меню
  работает «чётко, без осечек» (бета 4). НЕ проверено в игре отдельным отзывом: «уходящие» бойцы, отмена подъёма по
  верёвке, режим «там, где стреляю я», полёт и отряд после правок 1.2.
- Замечание от 15.11.2026: после выбора `helicover` в списке CLEO меню появляется с задержкой -> бета 5 (выпущена
  15.11.2026): меню открывается на следующем кадре. В игре пока НЕ подтверждено — ждём отзыв.

## 2. Файлы, сборка, тесты, выпуск
- `builder/asm_v25.py` — ассемблер CLEO (таблица опкодов sa_mobile + добавленные вручную).
  `Script.add(op, args)`; `check(op, [args], label)` — прыжок, когда условие ЛОЖНО; `op | 0x8000` — отрицание;
  `eq(var, val, label)` — прыжок, если НЕ равно; `call / ret / go`, `blob`, `set / get` (общие слоты 0DDC / 0DDD).
  Полярность: 0x0019 `var > n`, 0x0021 float `var > n`, 0x0023 `n > var`, 0x001d int `a > b`, 0x0025 float `a > b`,
  0x003b int равно. ПРИ КАЖДОЙ ПРАВКЕ УСЛОВИЙ перепроверять полярность (уже были перевёрнутые условия).
- `builder/build_v25.py` — Core (вертолёт, состояния, шлюз команд), Panel (меню), Launcher (`Helicover.csi`), Fire

  «мозг» отряда (Squad). `builder/threat_v41.py` — доска угроз и чтение следов пуль. `builder/msg_v42.py` — сообщения
  (`say`, приоритеты, язык). `builder/i18n_v12.py` — русские тексты и раскладка шрифта.
- `builder/build_all.py` — ВСЕГДА собирать через него: строит всё, пишет FXT, проверяет ключи, копирует в `install/` и
  `sources/`.
- Тесты (имитация игры на Python, `World` / `VM` в `test_v25.py`; остальные наборы берут её через `exec`):
  `test_v25.py` (112), `test_v40_squad.py` (117), `test_v12_realism.py` (79), `test_v12_i18n.py` (33) = 341.
  `check_wait_loops.py` (циклов без WAIT должно быть 0; подпрограмма, из которой нельзя вернуться без WAIT, — например
  `NAP` в Core — сама считается ожиданием). `tools/fuzz.py 1 300` — случайные приказы с двойными
  нажатиями и `invariants(w)` после каждого кадра. `tools/mutate.py` — мутанты: `--old` (37), `--12` (75), `--b4` (59), `--b5` (21); несколько
  прогонов параллельно — с разными `HC_MUT_ROOT`. «MISSED» = у правила нет теста.
- Команды: `cd builder && python3 build_all.py && python3 test_v25.py && python3 test_v40_squad.py &&
  python3 test_v12_realism.py && python3 test_v12_i18n.py && python3 check_wait_loops.py`
- Отчёты тестов: `build/*_tests.txt` -> копировать в `tests/`.
- Выпуск: `python3 builder/tools/make_release.py "Helicover 1.2" путь/Helicover_1.2_betaN_Android.zip` (папка
  `CLEO` с 8 файлами + `release/README_RU.txt`, `README_EN.txt`); коммит -> PR -> merge -> синхронизация ветки -> zip

- `install/` — 8 файлов: `Helicover.csi`, `Helicover.fxt` (английский, ASCII), `Helicover_RU.fxt` (двоичный, ключи U),

## 3. Как устроено

### Скрипты и общие переменные
- Общие слоты 0DDC / 0DDD от `STATE = 0x48456A00`: `CMD` +1, `HEART` +2 (метка времени Core каждый проход), `OPEN` +3,
  `PANELHEART` +4 (метка времени Panel). Полный список — в начале `build_v25.py`. Занято до +428
  (+410 свободен): 406 ROPE_BUSY, 407 SWAP_MSG, 408 TEAM_CREW, 409 LANG, 411 DISMISS_T, 412–414 PB_AIM, 415 ROPE_WAIT,
  416–423 LEAVE, 424 LEAVE_N, 425 AFTER_ROPE, 426 DISMISS_NEXT, 427 LEAVE_ROT, 428 NAP_UNTIL.
- Состояния Core: 0 нет вертолёта, 1 подготовка (в игре кадр-два), 2 следует, 3 зависание, 4 / 13 улетает, 5 / 6 сбой,
  7 / 11 / 15 посадка (15 аварийная), 8 / 9 / 12 на земле, 10 / 20 полёт на Гроув-стрит, 14 сбор экипажа,
  16 / 17 замена модели / экипажа, 18 «посадка невозможна», 19 подлёт для верёвки, 21 / 25 / 22 полёт к метке,
  23 ожидание выхода, 24 патруль.
- Приказы (`CMD`): 1 вызвать, 2 следовать, 3 ждать, 4 отпустить, 7 Гроув, 10 верёвка, 11 метка, 14 патруль,
  15 выход, 16 высадить отряд, 17 забрать отряд.
- Отряд: `ESCORT_ON` 0 нет, 1 на земле, 2 спускается, 3 возвращается, 4 потерян, 5 отпущен; `ESCORT_PENDING` 1 / 2 —
  подлёт для высадки / возврата; `ESCORT_CMD` 1 высадить, 2 забрать, 3 эвакуация; `ROPE_COMMAND`, `DROP_COMMAND`.

### Память игры (сборка пользователя, `GAME_OK` = STATE+330 проверяет подпись)
- Метка карты: `gMobileMenu+0x68` (0x8BE780+0x68), `RADAR_TRACE_OFS` 0xC21728. Опкод 0AB6 на CLEO Android вылетает.
- Следы пуль `CBulletTraces` 0xCFA500. `CFont::UsingRussianLanguage` 0xCE1771 (байт).
- `AddTrace` для выстрелов педов и CJ пишет СЛУЧАЙНЫЙ отрезок до 5 м на пути пули, не точные концы; точные — только
  у 06BC и полицейского вертолёта. След читается как ЛИНИЯ.
- 02E0 IS_CHAR_SHOOTING живёт ровно один кадр (ставит `CWeapon::Fire`, сбрасывает `CPed::ProcessControl`) — опрос
  каждый кадр.
- 009A CREATE_CHAR прибавляет 1.0 к z; 046C — водитель машины (игрок тоже, нет -> −1); 05DE TASK_WANDER_STANDARD
  (1 параметр); 09B4 в таблице игры нет.

### Правила мода (каждое закрыто тестом)
- Никаких телепортов людей: вертолёт создаётся на кольце 160 м вне поля зрения и улетает из виду; отставший бежит,
  через 60 с за 70 м отпускается; у верёвок ждут 25 с.
- Живого бойца никогда не отдают игре (01C2): в поле зрения — `LEAVE_ADD` (оружие убрано, уходит 05DE / выходит из
  машины 0633, 8 слотов, девятый вытесняет самого старого), вне поля зрения — удаление; Fire считает уходящих своими.
- Шлюз команд в Core (метка `GATE`): повтор включённого режима и полёта к той же метке — пропуск; `SQUAD_MOVING` —
  16 / 17 молча, 10 с «подождите»; пока верёвка выпущена для CJ (`ROPE_WAIT`): 10 = отмена, 17 = отряд вверх по этим
  верёвкам, 16 = группа прикрытия остаётся отрядом, 2 / 4 / 14 при группе прикрытия = отмена + `AFTER_ROPE`; при
  `ROPE_BUSY` — отказ `HCRBSY`; повтор выхода отбрасывается, пока выход уже идёт.
- Ground читает запросы шлюза в `ACT_NOT_BUSY` только после приземления группы; `ROPE_BUSY` = 1 с момента принятия
  заказа, снимается в `CLEANUP` до любых приказов.
- Язык: русский только при `GAME_OK` и флаге 0xCE1771, иначе английский; `RESOLVE_LANG` каждый проход Core.
  Раскладка шрифта «Русского»: А–Я 0x80–0x9F, а–я 0xA0–0xBF, Ё нет. FXT: ключи H… (англ.), U… (рус.).
- Меню (Panel): страницы 0 главная, 1 огонь, 2 настройки (5 строк + НАЗАД), 3 экипаж, 4 модель, 5 оружие,
  6 подтверждение «отпустить». Ключ главной: state·1000 + sit·100 + x (sit 0 нет вертолёта, 1 занят, 2 на земле,
  3 на борту). Строки хода: `TEAM_PHASE`, `ROPE_PHASE`. На борту строки «КНОПКА ВЫХОДА» — переключатели `EXIT_MODE`.
- Защита касаний (Panel, `HAS_PICK`): 0,35 с после принятого касания или смены страницы; на главной та же строка —
  раз в 1 с (считаются и отброшенные касания); касание по устаревшей странице только перерисовывает.
  Локальные Panel: заняты 0–29 (29 — срок запасной проверки Core), свободны 30–31. Пускач: 1–3.
- Открытие меню без пауз (бета 5). «Пульс» = метка времени игры 01BD. Пускач (`Helicover.csi`): `PANELHEART` не
  старше `PANEL_FRESH_MS` 1000 мс -> `OPEN` = 1 сразу; Panel (`ACQUIRE`): `HEART` не старше `CORE_FRESH_MS` 1500 мс ->
  сразу страница. Метка 0, устаревшая или «из будущего» (загрузка сохранения) -> запасной путь, прежняя проверка:
  ждать СМЕНЫ метки не дольше `PANEL_PROOF_MS` 650 мс (иначе «нет файлов» HCOFF / UCOFF) и `CORE_PROOF_MS` 250 мс
  (иначе страница OFFLINE). Устаревшая метка сама по себе никогда не значит «скрипта нет».
- Опрос Panel: `WATCH` и `MENU_POLL` каждый кадр (wait 0), `OFFLINE_POLL` 50 мс. После нажатия строки паузы нет:
  `CMD` записан -> `CHECK_MENU_STATUS`.
- Тик Core: подпрограмма `NAP` вместо wait 100 (в `IDLE` и `TICK_NORMAL_WAIT`): `NAP_UNTIL` = сейчас + 100, цикл
  wait 0 до этой метки, выход сразу при `CMD` != 0. Без приказов — те же проходы раз в 100 мс; приказ забирается
  за 1–2 кадра. Состояния 10 / 19 / 21 / 22 при `FROZEN` — по-прежнему каждый кадр; `DEPART_TICK` — wait 100.
  Регистры `NAP`: 17 и 19 (временные). Любой приказ Core обнуляет `CMD` за проход (тест перебирает 1..39 в 6 ситуациях) —
  если появится состояние, которое оставляет `CMD` висеть, `NAP` выродится в покадровый цикл.
- «Отпустить вертолёт» (`DISMISS_TICK`): ждёт верёвки и отряд, просит отзыв раз в 6 с, через 45 с улетает без отряда.
- «Там, где стреляю я»: цель по захвату игры (0457) -> своя линия по следам (не старше 0,9 с, отрезок смотрит туда
  же, куда CJ, ±100°) -> камера. Нагрузку мерить в каждом режиме при 30 к/с (`frame_ms = 33`).
- Сообщения: `say(s, key)`; приоритеты 4 действие / 3 тревога / 2 тактика / 1 болтовня; уровень HUD 2 / 1 / 0;
  длина текста ≤ 66 знаков.

## 4. Грабли
- Обе раскладки русского в бетах 1–2 (CP1251 и «клавиатурная» по `russian_table`) дали мусор: `russian_table` к шрифту
  не относится. Не выводить раскладку из бинарника без экрана. SanLTD — другой шрифт; пользователь его не хочет.
- v41 / 1.1: считал след пули точным отрезком — «стрелок по следу» почти не находился. Сказано пользователю.
- Перевёрнутые условия (бонус тяжёлого оружия, чтение следов во время стрельбы) — проверять полярность опкодов.
- Проба нагрузки только в одном режиме пропустила пик 5063 инструкций в «там, где стреляю я».
- Тест, который ищет «?» как признак нечитаемого знака, сталкивается с настоящим «?» в тексте — использовать U+FFFD.
- В имитации: состояние 1 длится один кадр; отряд «приземляется» мгновенно — держать на верёвке через
  `w.ped_heights`; `command()` шагает только Core — остальные скрипты шагать отдельно; между нажатиями одной строки
  в тестах нужна пауза ≥ 1 с.
- Мутант может «пройти», если тест смотрит не туда (стрельба по координатам 06BC без дескриптора цели) — проверять
  `FIRE_TARGET` и сам факт выстрелов.
- Фиксированные паузы «для проверки, что скрипт жив» (400 + 250 + 250 мс) давали секунду задержки открытия меню.
- `NAP` сначала сравнивал «сейчас > срок» — при 10 к/с тик Core стал 200 мс вместо 100 (поймали старые тесты скорости
  полёта). Нужно «сейчас >= срок»: `check(0x801d, [срок, сейчас], 'NAP_LOOP')`.
- Ускорение приёма приказа сдвигает на кадр «стартовые» кадры в тестах, которые телепортируют вертолёт посреди паузы
  Core (тест скорости подлёта к верёвке пропускает первые 4 кадра).
- 0DF4 (опрос меню) имеет аргумент 250 — возможно, CLEO сообщает о касании до 0,25 с подряд. Страница теперь меняется
  сразу, поэтому защита касаний (0,35 с) обязательна: тест «залипшего» касания это проверяет. Не уменьшать 0,35 с
  ниже 0,25 с.
- Не знаю, идут ли скрипты и время игры, пока открыт список CLEO: поэтому у проверки «пульса» есть запасной путь, а
  не сразу «нет файлов».

## 5. Пожелания пользователя
- Меню только через CLEO; язык следует за языком игры (русский стандарт -> русский, иначе английский), выбора языка
  в меню не нужно.
- Высадка только кнопкой выхода; строки на борту — переключатели.
- Декор (модель, форма, оружие) меняется сразу, без «реализма».
- Повторные нажатия ничего не должны ломать; «идеальная логика всего мода», удобно.
- Меню должно открываться и реагировать сразу, плавно.
- Не коммитить файлы игры. Архив присылать файлом в чат.
