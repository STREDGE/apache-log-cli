# CLEO UI — новый вид меню CLEO (AML)

Памятка для Claude. Обновлять при каждой работе над модом (версия, что изменилось, новые факты, открытые вопросы).
Общие правила работы с пользователем и его устройство — в `PROJECT_MEMORY_RU.txt`.

## 1. Что это и статус
- AML-мод `libCleoUI64.so`: меняет вид меню CLEO (список скриптов и меню любых скриптов) в игре пользователя.
  Отдельный проект, НЕ часть Helicover: своя папка `cleo-ui/`, свои PR, свой архив `CleoUI_x.y.zip`.
- **Версия 0.2 «техно-неон». Проверена пользователем на планшете (2000×1250): «всё красиво очень», вылетов нет,
  вкладка «ЗАКРЫТЬ» и русский текст на месте.**
- Работает только с CLEO ANDROID (64-260403) внутри APK пользователя; с любой другой сборкой мод ничего не трогает.

## 2. Файлы, сборка, тесты, выпуск
- `cleo-ui/cleoui.c` — мод (C без libc). `cleo-ui/build.sh` — сборка без NDK (как у Touch x4), выход
  `build/cleo-ui/libCleoUI64.so`, копия в `cleo-ui/`.
- `cleo-ui/tools/unpack_cleo.py` — запускает загрузчик `libSAcleo64.so` в unicorn (импорты и JNI на Python) и пишет
  рядом `.image` — распакованный образ. Запускать из папки без чужих файлов.
- `cleo-ui/test_cleoui.py` — 16 проверок: настоящий код меню CLEO из образа + мод в эмуляторе.
- `cleo-ui/tools/preview.py` — PNG меню из эмулятора для 2000×1250, 2400×1080, 1280×720, 1024×768 (шрифт условный).
  Смотреть эти картинки самому ДО отправки пользователю.
- `cleo-ui/cleoui_probe.c`, `test_probe.py` — «диктофон» первого шага (не понадобился, не распространяется).
- `cleo-ui/README_RU.txt` — описание для пользователя.
- Команды:
  `sh cleo-ui/build.sh`
  `python3 cleo-ui/tools/unpack_cleo.py путь/libSAcleo64.so`
  `python3 cleo-ui/test_cleoui.py путь/libSAcleo64.so.image`
  `python3 cleo-ui/tools/preview.py путь/libSAcleo64.so.image папка`
- Файлы пользователя (в репозиторий не класть): APK по частям в uploads сессии
  (`9fefac1b-lib_arm64-v8a_part_2.zip` -> `arm64-v8a/libSAcleo64.so`, 493624 байта, sha1 `03276a2e…`);
  в scratchpad: `cleolib/libSAcleo64.so`, `.image`, `inner.bin` (распакованная часть), `strings.txt`.
  Если scratchpad пуст — попросить `libSAcleo64.so` снова (маленький файл) и прогнать `unpack_cleo.py`.
- Выпуск: коммит -> PR -> merge -> синхронизация ветки -> zip (`mods/libCleoUI64.so` + `README_RU.txt`) + картинки.
- На устройстве: `mods/cleoui_log.txt` («new look installed» = всё встало), настройки
  `configs/net.helicover.cleoui.ini` (`Enabled`, `Accent`, `Animation`, `Dim`).

## 3. Как устроено

### CLEO пользователя
- `libSAcleo64.so` лежит в APK (`lib/arm64-v8a`), это не мод AML и не открытая обёртка RusJJ. В APK также `libAML.so`,
  fastman92 limit adjuster 7.6 (называет игру GTA SA 2.10), `libthreadfix.so`. `libGTASA.so` в APK = файл, который уже
  есть (CRC совпал).
- Библиотека упакована: первый сегмент — загрузчик, во втором — сжатые zlib данные (224744 -> 531321 байт), секции
  `.context` / `.exframe`, строки зашифрованы, экспорт только `JNI_OnLoad`. Загрузчик распаковывает настоящую
  библиотеку в собственный образ начиная с vaddr **0x88000**. Ключ от подписи APK не зависит (распаковалось в эмуляторе
  без неё).
- Внутри: «CLEO ANDROID (64-260403) (C) Alexander Blade», «game ver: GTASA 2.10 arm64-v8a», GlossHook, libc++.
  Скрипты `%s/cleo/sa/`, журнал `%s/cleo/cleo.log`, плагины `cleoplugins`.

### Как CLEO рисует (смещения от начала распакованной части; в игре адрес = база libSAcleo64 + 0x88000 + смещение)
- Перехват `CHud::Draw` -> обработчик 0x363c0: стрелка-подсказка «OPEN CLEO MENU» (0x363dc) и, если меню открыто
  (`[0x7cfcc] != -1`), рисование меню 0x36d70.
- Всё рисуется ДВУМЯ внутренними функциями через указатели в данных:
  - rect = `*(0x27d3b8)` -> 0x3659c `(CRGBA*, x1,y1,x2,y2,x3,y3,x4,y4)` в долях экрана; порядок точек: левый верх,
    правый верх, левый низ, правый низ; умножает на RsGlobal (указатель 0x27d408: +8 ширина, +12 высота) и зовёт
    `CSprite2d::Draw2DPolygon` (указатель 0x27d3d8). Можно рисовать любые четырёхугольники.
  - text = `*(0x27d3c0)` -> 0x365dc `(gxt*, align, CRGBA*, style, x, y, sx, sy)`: align 0 центр, 1 влево, 2 вправо;
    style 0 -> `SetFontStyle(2)`, масштаб ×1.4 / ×1.3; style 1 -> `SetFontStyle(3)`, ×1.9 / ×1.5; style 2 ->
    `SetFontStyle(0)`. Пишет `CFont::Details` (указатель 0x27d3f0: +0 цвет, +4 масштаб, +0x18 / 0x19 / 0x1a
    выравнивание, +0x1d пропорциональный), зовёт `CFont::PrintString` (0x27d400), потом восстанавливает Details.
    `SetFontStyle` — указатель 0x27d3f8.
- Меню (0x36d70): панель цвета (55,127,175,150) x 0.35–0.65, y 0.12–0.92; заголовок (0.5, 0.09) масштаб 1.0 / 2.25,
  style 1; CLOSE (0.2, 0.87) align 1, style 1, масштаб 0.9 / 2.4; номер страницы (0.61, 0.16) при числе страниц ≥ 2;
  до 8 строк: x 0.5, y = 0.20 + 0.09·k, style 0, масштаб 0.75 / 2.25; стрелки страниц — два треугольника цвета
  0x27d3c8 = (55,127,175,100), нажатая — альфа 180 (0x27d3cc).
- Данные меню: `std::string` заголовок 0x27d820, CLOSE 0x27d838; `vector<u16string>` строк 0x27d850 (24 байта на
  строку); число страниц 0x27d868; текущая страница `[0x7cfcc]`; выбранная строка 0x27d86c (−1 нет, −2 CLOSE); время
  выбора 0x27d870; счётчик подсветки 0x27d87c (3 кадра), цвет нажатой строки 0x27d3d0 = (40,235,24).
- Зоны нажатия (доли экрана, по 4 float): CLOSE 0x27d880 = (0.2, 0.87, 0.3, 0.97) — CLEO пишет её КАЖДЫЙ кадр ПЕРЕД
  вызовом текста CLOSE; строки 0x27d8d0 (16 байт на строку: x 0.38–0.62, y+0.01..y+0.08) — пишет ПОСЛЕ вызова текста
  строки; стрелки 0x27d890 / 0x27d8b0.
- Касания: CLEO перехватывает `AND_TouchEvent(type, id, x, y)`; обработчик 0x36050 переводит позицию в целые проценты и
  при type 2 (палец опущен) зовёт 0x36b1c(x, y): строка -> выбор и подсветка; иначе зона CLOSE -> −2; иначе стрелки (по
  расстоянию до центра). Нажатие срабатывает В МОМЕНТ КАСАНИЯ.
- Список скриптов «CLEO MENU» — то же самое меню (заголовок «CLEO MENU», строки = имена скриптов).

### Что делает мод
- Не меняет ни одной инструкции. Поток-ожидатель (до 2 минут, шаг 0,2 с) ждёт, пока CLEO заполнит указатели; сверяет
  строку версии (0x1bc30), оба указателя (должны указывать на 0x3659c / 0x365dc) и первые 4 инструкции обеих функций;
  затем атомарно ставит в 0x27d3b8 / 0x27d3c0 свои `ui_rect` / `ui_text`. При любом несовпадении — ничего.
- `ui_rect`: панель узнаётся по цвету и месту -> `draw_panel()`; стрелки (альфа 100 / 180) и красная стрелка
  подсказки перекрашиваются; всё остальное проходит без изменений.
- `ui_text`: заголовок, CLOSE, строки, номер страницы узнаются по align / style / месту; остальное без изменений.
- `draw_panel()` (всё в пикселях, размеры экрана из RsGlobal каждый кадр): затемнение экрана; панель со срезанными
  углами (`plate_fill`), контур со свечением (`contour` / `glow`: 4 слоя); шапка: клин, 3 косые полосы, блик раз в
  3,4 с, светящаяся линия. Ширина = clamp(0.5·H/W, 0.27, 0.33)·W; верх 0.075·H, низ шапки 0.175·H,
  низ панели (0.21 + 0.09·строк)·H — плавно; линия = max(2, H/540) px; срез 0.024·H.
- Текст: по центру ячейки. Замеры со скриншота пользователя (2000×1250): высота глифа на единицу sy CLEO —
  0.0089·H (style 0), 0.0108·H (style 1), пустое место сверху 0.003·H. Строки ×1.12, заголовок ×0.90, CLOSE ×0.80.
- Подгонка ширины: `CFont::GetStringWidth` игры (`libGTASA` 0x6ce760, начало `0x6db923e9 0xa9016ffc` сверяется) с той
  же подготовкой Details, что у CLEO; результат — пиксели; кеш на 16 текстов; множитель не меньше 0.5.
- CLOSE: вкладка справа от шапки; мод переписывает зону 0x27d880 в `ui_text` (сразу после записи CLEO).
- Нажатая строка: зелёный цвет CLEO -> запомнить y и время; плашка 90 мс разгон + 120 мс + 220 мс затухание.
- Открытие 140 мс (пауза между кадрами меню > 250 мс = «открыто заново»); строки проявляются по 9 мс со сдвигом,
  с первого кадра видны (альфа ≥ 0.22). Смена подписи (хеш заголовка + число строк + страница) без паузы = переход 90 мс.
- Русский (флаг `CFont::UsingRussianLanguage`, `libGTASA` 0xCE1771): CLOSE -> «ЗАКРЫТЬ», OPEN CLEO MENU -> «МЕНЮ CLEO»;
  текст скриптов: UTF-8 (D0/D1 + 80–BF) или CP1251 (есть байт C0–FF) -> коды шрифта игры (А–Я 0x80–0x9F, а–я
  0xA0–0xBF, Ё -> Е). Текст уже в кодах игры (нет байтов > 0xBF) не трогается.
- Настройки SAUtils (`AddClickableItem`, тип 5): CLEO UI, CLEO UI Colour (Orange / Blue / Green / Red / White),
  CLEO UI Animation, CLEO UI Dim.

## 4. Грабли
- CLEO защищён: править его «по байтам» нельзя и не нужно. Не перехватывать `DrawRect` — CLEO рисует
  `Draw2DPolygon` («диктофон» 0.1 ловил не то).
- Список скриптов — НЕ подсказка игры, а то же меню (раньше ошибочно писал обратное).
- В 0.1 пауза между кадрами в тестах 1000 мс считалась «повторным открытием» — в тестах шаги < 250 мс.
- CP1251 «Ё / ё» (0xA8 / 0xB8) совпадают с кодами игры «и / ш»: кодировку определять по всей строке, а не по символу.
- Первый кадр анимации не должен быть пустым (альфа 0 = «тупит»).
- Эмулятор не рисует шрифт игры: размеры текста сверять только по скриншотам пользователя.
- Зоны строк двигать нельзя (CLEO пишет их после вызова текста). Анимация закрытия невозможна: CLEO просто перестаёт
  вызывать отрисовку.
- `S` в `test_cleoui.py` — список регистров; не использовать это имя для путей в инструментах.
